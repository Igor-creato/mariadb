# WordPress Cashback Plugin & Browser Extension

## Обзор

Этот проект представляет собой комплексное решение для системы кэшбэка, состоящее из WordPress-плагина и браузерного расширения. Позволяет пользователям получать кэшбэк с покупок в интернет-магазинах через партнерские программы (CPA-сети).

## Архитектура

### WordPress Плагин

#### Основные компоненты

1. **CashbackPlugin** ([cashback-plugin.php](cashback-plugin.php))
   - Главный класс-оркестратор, управляющий жизненным циклом плагина
   - Загружает все зависимости и инициализирует компоненты
   - Обрабатывает активацию/деактивацию/удаление плагина
   - Проверяет совместимость с PHP, WordPress и WooCommerce

2. **Mariadb_Plugin** ([mariadb.php](mariadb.php))
   - Управляет схемой базы данных
   - Создает таблицы, триггеры и события MySQL
   - Обеспечивает целостность данных через ограничения и проверки
   - Генерирует уникальные идентификаторы для заявок на выплату

3. **CashbackWithdrawal** ([cashback-withdrawal.php](cashback-withdrawal.php))
   - Обрабатывает вывод кэшбэка пользователями
   - Управляет балансами и заявками на выплату
   - Реализует защиту от гонок и дублирования запросов
   - Обеспечивает шифрование реквизитов пользователей

4. **WC_Affiliate_URL_Params** ([wc-affiliate-url-params.php](wc-affiliate-url-params.php))
   - Управляет партнерскими параметрами URL для внешних товаров
   - Обеспечивает отслеживание кликов и активацию кэшбэка
   - Реализует rate limiting для предотвращения спама
   - Показывает информацию о кэшбэке на страницах товаров

5. **Cashback_REST_API** ([includes/class-cashback-rest-api.php](includes/class-cashback-rest-api.php))
   - Предоставляет REST API для взаимодействия с браузерным расширением
   - Обрабатывает аутентификацию запросов от расширения
   - Управляет списком магазинов, профилями и транзакциями

6. **Cashback_Encryption** ([includes/class-cashback-encryption.php](includes/class-cashback-encryption.php))
   - Обеспечивает шифрование чувствительных данных пользователей
   - Использует AES-256-GCM для новых записей (аутентифицированное шифрование)
   - Поддерживает обратную совместимость с AES-256-CBC для старых данных
   - Реализует маскирование и хеширование реквизитов

### Браузерное расширение

#### Основные компоненты

1. **Service Worker** ([brauzer/background/service-worker.js](brauzer/background/service-worker.js))
   - Управляет состоянием кэшбэка и иконками расширения
   - Обнаруживает конкурирующие кэшбэк-сервисы
   - Обрабатывает навигацию и детектирует перехват кэшбэка
   - Синхронизирует состояние с сервером

2. **Content Script** ([brauzer/content/content.js](brauzer/content/content.js))
   - Показывает уведомления о кэшбэке на страницах магазинов
   - Обнаруживает конкурирующие affiliate-ссылки
   - Обеспечивает взаимодействие с Service Worker
   - Рендерит уведомления через Shadow DOM

3. **Popup** ([brauzer/popup/popup.js](brauzer/popup/popup.js))
   - Отображает информацию о пользователе и балансе
   - Показывает статус кэшбэка для текущего сайта
   - Обрабатывает активацию кэшбэка
   - Отображает последние транзакции

## Функциональность

### Партнерские ссылки и отслеживание

- Интеграция с CPA-сетями (Admitad, EPN и другие)
- Автоматическое добавление партнерских параметров к URL товаров
- Серверное логирование кликов с уникальными идентификаторами
- Rate limiting для предотвращения спама и click fraud
- Поддержка индивидуальных параметров для каждого товара

### Управление выплатами

- Система балансов (доступный, в обработке, выплаченный, замороженный)
- Защита от гонок при обработке запросов на вывод
- Идемпотентность операций с использованием уникальных ключей
- Шифрование реквизитов пользователей
- Поддержка различных способов выплаты (СБП, МИР и др.)

### Антифрод-модуль

- Сбор и анализ browser fingerprint
- 7 автоматических проверок подозрительной активности
- Определение общих IP, реквизитов и отпечатков
- Мониторинг частоты выводов и аномалий сумм
- Административная панель для управления алертами

### Интеграция с WooCommerce

- Поддержка внешних товаров с партнерскими ссылками
- Совместимость с HPOS (High-Performance Order Storage)
- Отображение кэшбэка на страницах товаров
- Интеграция с системой учетных записей WordPress

### Браузерное расширение

- Автоматическое определение магазинов-партнеров
- Активация кэшбэка одним кликом
- Обнаружение перехвата кэшбэка другими сервисами
- Уведомления о статусе кэшбэка
- Интеграция с REST API плагина

## Безопасность

- AES-256-GCM шифрование реквизитов (аутентифицированное)
- Защита от SQL-инъекций через подготовленные выражения
- CSRF-защита для форм и AJAX-запросов
- Rate limiting для предотвращения злоупотреблений
- Защита от IP spoofing при определении клиентского IP
- Аудит-лог чувствительных операций

## Таблицы базы данных

Плагин создает 18 таблиц для хранения данных:

- `cashback_transactions` - транзакции кэшбэка
- `cashback_user_balance` - балансы пользователей
- `cashback_payout_requests` - заявки на выплату
- `cashback_user_profile` - профили пользователей
- `cashback_payout_methods` - способы выплаты
- `cashback_banks` - справочник банков
- `cashback_affiliate_networks` - партнерские сети
- `cashback_affiliate_network_params` - параметры сетей
- `cashback_click_log` - лог кликов
- `cashback_webhooks` - сырой вебхук-лог
- `cashback_unregistered_transactions` - транзакции гостей
- `cashback_audit_log` - аудит-лог
- `cashback_support_tickets` - тикеты поддержки
- `cashback_support_messages` - сообщения поддержки
- `cashback_support_attachments` - вложения поддержки
- `cashback_fraud_alerts` - алерты антифрауда
- `cashback_fraud_signals` - сигналы антифрауда
- `cashback_user_fingerprints` - отпечатки пользователей

## Триггеры и события

Плагин использует MySQL триггеры для обеспечения целостности данных:

- Автоматический расчет кэшбэка при вставке/обновлении транзакций
- Валидация переходов статусов транзакций
- Защита от удаления/изменения финальных записей
- Управление баном пользователей и заморозкой балансов

Также используются MySQL события для периодических задач:

- Начисление кэшбэка по завершенным транзакциям
- Очистка старых вебхуков и логов кликов
- Пометка неактивных профилей

## API интеграции

- Интеграция с CPA-сетями через API (Admitad, EPN)
- Синхронизация статусов транзакций каждые 2 часа
- Валидация локальных данных с данными из API
- OAuth2 аутентификация с шифрованием credentials

## Управление через админку

Плагин предоставляет полный административный интерфейс:

- Управление заявками на выплату
- Управление пользователями и банами
- Управление способами выплат и банками
- Управление партнерскими сетями
- Статистика и аналитика
- Логи кликов и транзакций
- Настройки антифрауда
- Валидация API данных

## Установка и настройка

1. Установить плагин как обычный WordPress плагин
2. Убедиться, что включена поддержка событий MySQL (event_scheduler = ON)
3. Настроить партнерские сети и параметры
4. Установить браузерное расширение
5. Настроить шифрование (ключ будет сгенерирован автоматически)
