# ИНСТРУКЦИЯ ПО СОЗДАНИЮ РЕЛИЗА
# =====================================================

# 1. Создайте чистую директорию для релиза:
#    mkdir cashback-plugin-release
#
# 2. Скопируйте только необходимые файлы:
#    rsync -av --files-from=INSTALL_FILES.txt . cashback-plugin-release/
#
# 3. Создайте ZIP архив:
#    cd cashback-plugin-release/..
#    zip -r cashback-plugin-1.0.0.zip cashback-plugin-release/
#
# 4. Загрузите ZIP в WordPress Admin → Плагины → Добавить новый
