# Changelog

Все значимые изменения в этом проекте будут документироваться в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/),
и этот проект придерживается [Semantic Versioning](https://semver.org/lang/ru/).

## [Unreleased]

### Added
- Улучшенная безопасность: валидация префиксов таблиц в триггерах и событиях
- Composer support для управления зависимостями
- PHPStan для статического анализа кода (level 6)
- WordPress Coding Standards (PHPCS/PHPCBF)
- Проверка совместимости версий PHP, WordPress и WooCommerce
- Полная интернационализация (i18n) - поддержка переводов
- Uninstall script для полной очистки при удалении плагина
- Документация: README.md, SECURITY.md, CONTRIBUTING.md
- .editorconfig для единого стиля кода
- Улучшенный .gitignore

### Fixed
- **SECURITY**: Добавлена валидация префиксов таблиц для защиты от SQL-инъекций
- **SECURITY**: Улучшено экранирование вывода в admin notices
- **SECURITY**: Исправлен вывод счетчика в CSS (использование esc_js)
- Улучшена обработка ошибок при активации плагина

### Changed
- Обновлен заголовок плагина с метаданными о требованиях
- Улучшена структура проекта

## [1.0.0] - 2026-02-14

### Added
- Первый публичный релиз
- Система начисления кэшбэка
  - Автоматический расчет на основе комиссии партнера
  - Индивидуальные ставки кэшбэка для каждого пользователя
  - Защита от дублирования транзакций
  - Триггеры для автоматического расчета
- Управление балансами
  - Доступный баланс
  - Баланс в ожидании выплаты
  - Выплаченный баланс
  - Заблокированный баланс
  - Версионирование для защиты от race conditions
- Система выплат
  - Заявки на выплату с идемпотентностью
  - Поддержка различных методов (СБП, карты, электронные кошельки)
  - Интеграция с банками
  - Отслеживание статусов (waiting, processing, paid, failed, declined)
  - Автоматический возврат средств при ошибках
- Система поддержки
  - Тикеты для пользователей в WooCommerce My Account
  - Административная панель для обработки тикетов
  - Приоритеты (срочный, обычный, не срочный)
  - Статусы (открыт, отвечен, закрыт)
  - Email уведомления
  - Автоудаление закрытых тикетов через 30 дней
  - Rate limiting (5 тикетов/час, 20 ответов/час)
  - Счетчик непрочитанных сообщений
- Партнерская программа
  - Отслеживание affiliate параметров в URL
  - Webhook интеграции
  - Таблица незарегистрированных транзакций
  - Автоматическая дедупликация webhook
- Административная панель
  - Управление пользователями
  - Управление выплатами
  - Управление методами выплат
  - Управление банками
  - Просмотр истории транзакций
- MySQL триггеры
  - Автоматический расчет кэшбэка
  - Защита от удаления финальных транзакций
  - Защита от изменения выплаченных заявок
  - Автоматическая установка banned_at
- MySQL события
  - Ежедневное начисление подтвержденного кэшбэка
  - Очистка старых webhook (>6 месяцев)
  - Пометка неактивных профилей (>6 месяцев)
- Безопасность
  - Nonce-проверка для всех AJAX запросов
  - Проверка прав доступа (capabilities)
  - Валидация и санитизация входных данных
  - Экранирование выходных данных
  - Prepared statements для SQL
  - Rate limiting
  - Транзакции для критических операций
  - Идемпотентность операций

### Security
- Полная защита от CSRF атак
- Защита от XSS
- Защита от SQL-инъекций
- Валидация типов данных (declare(strict_types=1))
