# Cashback Plugin

Объединенный плагин для WordPress и WooCommerce, предоставляющий систему кэшбэка и аффилиат-партнерства.

## Описание

Cashback Plugin - это комплексное решение для создания программы лояльности на базе WooCommerce. Плагин включает:

- ✅ Система начисления кэшбэка
- ✅ Управление балансами пользователей
- ✅ Заявки на выплаты
- ✅ Система поддержки (тикеты)
- ✅ Партнерская программа
- ✅ Административная панель
- ✅ Webhook интеграции

## Требования

- **PHP:** 7.4 или выше
- **WordPress:** 6.2 или выше
- **WooCommerce:** 5.0 или выше
- **MySQL/MariaDB:** 5.7+ / 10.2+ (с поддержкой триггеров и событий)

## Установка

### Автоматическая установка

1. Загрузите плагин через WordPress Admin → Плагины → Добавить новый
2. Активируйте плагин

### Ручная установка

1. Загрузите файлы плагина в `/wp-content/plugins/mariadb/`
2. Перейдите в WordPress Admin → Плагины
3. Активируйте "Cashback Plugin"

### Установка зависимостей для разработки

```bash
composer install
```

## Функциональность

### Кэшбэк система

- Автоматический расчет кэшбэка на основе комиссии партнера
- Индивидуальные ставки кэшбэка для каждого пользователя
- Защита от дублирования транзакций
- Автоматическое начисление доступного баланса

### Выплаты

- Заявки на выплату с защитой от дублирования
- Поддержка различных методов выплат (СБП, карты, электронные кошельки)
- Интеграция с банками
- Отслеживание статусов выплат

### Система поддержки

- Система тикетов для пользователей
- Панель администратора для обработки тикетов
- Уведомления по email
- Автоматическое удаление закрытых тикетов через 30 дней

## Структура базы данных

Плагин создает следующие таблицы:

- `wp_cashback_payout_requests` - Заявки на выплаты
- `wp_cashback_transactions` - Транзакции кэшбэка
- `wp_cashback_unregistered_transactions` - Транзакции незарегистрированных
- `wp_cashback_user_balance` - Балансы пользователей
- `wp_cashback_webhooks` - Входящие webhook
- `wp_cashback_user_profile` - Профили пользователей
- `wp_cashback_payout_methods` - Методы выплат
- `wp_cashback_banks` - Справочник банков
- `wp_cashback_support_tickets` - Тикеты поддержки
- `wp_cashback_support_messages` - Сообщения в тикетах

### Триггеры

- Автоматический расчет кэшбэка при вставке/обновлении
- Защита от удаления/изменения финальных транзакций
- Автоматическая установка даты блокировки пользователя

### События (Events)

- Ежедневное начисление подтвержденного кэшбэка
- Очистка старых webhook (старше 6 месяцев)
- Пометка неактивных профилей

## Безопасность

- ✅ Валидация всех входных данных

## Хуки для разработчиков

### Actions

```php
// После активации плагина
do_action('cashback_plugin_activated');

// Перед деактивацией
do_action('cashback_plugin_deactivating');
```

### Filters

```php
// Изменить минимальную сумму выплаты
apply_filters('cashback_min_payout_amount', 100);

// Изменить ставку кэшбэка по умолчанию
apply_filters('cashback_default_rate', 60);
```

## Удаление

При удалении плагина через WordPress Admin:

1. Удаляются все таблицы
2. Удаляются все триггеры и события
3. Удаляются все опции плагина
4. Отменяются запланированные задачи cron

**Внимание:** Все данные будут безвозвратно удалены!
