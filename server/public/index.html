Подключение
Настройте эти URL в WordPress Plugin Admin → API Validation → Credentials
🟠 Admitad — настройки сети
Убедитесь что credentials совпадают с настройками в разделе «Credentials» этого сервера.
api_base_url (оставьте пустым или укажите)
http://host.docker.internal:3000/admitad
api_token_endpoint
http://host.docker.internal:3000/admitad/token/
api_actions_endpoint
http://host.docker.internal:3000/admitad/statistics/actions/
api_user_field (subid2 = user_id)
subid2
api_click_field (subid1 = click_id)
subid1
api_status_map (JSON)
{"pending":"waiting","approved":"completed","declined":"declined","hold":"waiting"}
🟣 EPN — настройки сети
api_base_url (для SSID и token)
http://host.docker.internal:3000/epn
api_token_endpoint
http://host.docker.internal:3000/epn/token
api_actions_endpoint
http://host.docker.internal:3000/epn/transactions/user
api_user_field (sub2 = user_id)
sub2
api_click_field (click_id = click_id)
click_id
api_status_map (JSON)
{"pending":"waiting","approved":"completed","rejected":"declined","canceled":"declined","hold":"waiting"}
Если WordPress на хосте (не в Docker)
Замените host.docker.internal на localhost в URL выше.
Пример api_token_endpoint для Admitad
http://localhost:3000/admitad/token/
